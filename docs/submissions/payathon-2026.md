## 可直接使用的作品文案

**作品名称：** 拾级 Gradus

**一句话介绍：** 把模糊学习目标变成有真实资源支撑、按认知难度和日程排好的可执行计划。

**作品简介：** 拾级面向自主学习者。输入“从零学 Python”这样的目标后，系统先解析学习意图，再检索并校验学习资源，按布鲁姆认知层级生成子任务，核查计划可执行性并安排到日历。用户可以按天执行、打卡，并在甘特视图中查看进度。付费方案为 AI 规划次数包：购买后额度归属登录账号，每次成功生成或重生成计划扣 1 次；失败或结果不确定时保留恢复路径。正式商品价格和收款能力以支付宝配置及审核结果为准。

**解决的问题：** 普通待办工具要求用户先自行拆任务；通用 AI 规划可能给出失效链接，多个目标还容易挤在同一段时间。拾级把“拆解、找资料、校验、排期”做成一条可交付流程，让用户拿到下一步具体做什么、用什么资料、何时做。

**产品亮点：**

1. AI 只提出检索意图，服务端检索真实资源并检查链接，减少凭空编造的资料。
2. 计划从理解到应用逐级推进，并经过独立核查与必要修订。
3. 多目标排期考虑已有任务，交付到每日任务面板与甘特视图。
4. 支付权益按稳定的服务端用户 ID 归属；成功生成后按次扣减，扣次及计划交付记录可追踪。

**产品体验地址：** https://talk-task.vercel.app/

**观猹上架页：** https://watcha.cn/products/shi-ji

**代码地址（如表单要求）：** https://github.com/melondy101/Gradus

**支付集成说明：** 拾级服务端向爱猹收查询 10/30 次权益和购买入口。用户在平台托管页面完成购买，返回拾级后重新查询权益；回跳本身不被视为付款成功。AI 规划优先使用已有本地试用/兑换额度，耗尽后以服务端幂等键扣减爱猹收额度，并在数据库事务中交付计划。浏览器不持有 API Key，也不能指定扣次用户 ID。正式环境与沙箱使用不同商品、权益 ID 和 Key。
