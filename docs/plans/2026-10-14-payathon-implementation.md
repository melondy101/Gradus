## 成本与上线闸门

本地开发环境已配置官方 DeepSeek `deepseek-flash`。生产环境存在 AI 模型变量，但其值未核对，不能据此推断服务商和成本。服务端现在记录每次模型调用的输入、输出和缓存命中 Token 数量，不记录用户提示词。用 30–50 次真实规划采样，按实际模型价格计算 P50/P95 成本；同时核对豆包搜索请求数、商户费率与退款规则，再确认最终售价。当前售价属于待验证的实验定价。

退款只应处理未使用的额度；代码目前没有自动退款入口，须在商户后台人工核对交易与剩余权益。正式开放之前还需补全退款状态机与对账流程。支付宝网页接入总指南目前错误地展示眼镜 SDK 内容；实现依据同一文档目录下的[下单](https://aipay.alipay.com/docs/vibe-pay/ai-web-app-payment-qianyi/api-list/alipay-trade-page-pay.html)、[查询](https://aipay.alipay.com/docs/vibe-pay/ai-web-app-payment-qianyi/api-list/alipay-trade-query.html)、[异步通知](https://aipay.alipay.com/docs/vibe-pay/ai-web-app-payment-qianyi/api-list/async-notify-verify.html)接口说明，并应以签约后台的当前要求复核。

## 验收路径

`进入拾级 → 注册/登录 → 免费生成一次计划 → 打开会员中心购买 → 支付宝付款 → 返回订单核对页 → 额度到账 → 再生成 → 余额减少`。检查跨设备余额一致、并发请求只扣一次、失败归还、重复通知不重发、伪造通知不发放、交易查询能补偿漏通知，并在真实手机上走通完整流程。比赛提交还需要真实付款用户与产品演示材料，不能把沙箱交易当作有效用户数。
