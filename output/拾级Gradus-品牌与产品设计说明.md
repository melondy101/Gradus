## 1. 品牌系统

### 1.1 标识：三级台阶

取「拾级而上」意象——三级递高的圆角台阶，顶点一级用点缀黄，象征「每一步都被看见」。

```
<svg viewBox="0 0 96 44">
  <rect x="0"  y="32" width="26" height="12" rx="4" fill="#111111"/>
  <rect x="35" y="18" width="26" height="26" rx="4" fill="#111111"/>
  <rect x="70" y="0"  width="26" height="44" rx="4" fill="#F5C518"/>
</svg>
```

- 最小使用尺寸 26px 宽（侧边栏），最大 40px（Footer）
- 字标：「拾级」Noto Sans SC Bold；深色底反白
- 禁用：官方 Oats / Ariso 的名称、logo、文案、燕麦图标与截图内容（本设计为全新原创）

### 1.3 字体

| 角色 | 字体 | 规格 |
|---|---|---|
| 大标题 | Noto Sans SC Black | 64px / 行高 74（Hero、CTA） |
| 章节标题 | Noto Sans SC Bold | 44px / 行高 56 |
| 正文 | Noto Sans SC Regular | 15–16px |
| 眉题 / 元信息 | JetBrains Mono Medium | 10–12px，全大写英文 + 中文 |
| 界面数值 | Noto Sans SC Black | 28px（统计卡） |

### 1.4 组件规范

- **按钮**：主按钮墨色药丸（radius 999，padding 26/13，白字）；次按钮 1px 墨色描边药丸；App 内主按钮用 radius 12 方圆角（输入框同高 56）
- **卡片**：白卡或描边深卡，radius 16，1px 细描边，padding 24，几乎无阴影（Hero mockup 与弹层除外）
- **输入**：浅底 `#FAF8F3` + 1px 描边 `#E1DCF`，radius 12
- **章节分隔**：奶油 / 浅奶油 / 深色带交替

## 2. Landing Page（8 段，1440px 宽）

1. **吸顶导航** — 台阶标识 + 字标、居中链接组、登录链接 + 墨色药丸 CTA
2. **Hero** — 左文右图：更新徽章、图标标语行、三行 64px 大标题（黄色句号结尾）、说明文、三按钮、脚注；右侧产品界面 mockup（白卡 + 细描边 + 轻投影）与悬浮 AI pill「AI 正在生成计划 阶段 2/4」
3. **What's New** — 更新列表 + 深色 GitHub CTA 卡（仓库地址 + 「在 GitHub 上查看」按钮）
4. **How it works** — 浅奶油带，四步流程
5. **核心能力** — 2 行 × 3 列白卡网格（AI 目标拆解 / 资源检索与校验 / 全局接续排期 / 甘特图与进度看板 / 自动核查修订 / Bloom 难度递进）
6. **隐私（深色带）** — 黄色眉题 + 白标题 + 四张描边暗卡（BYOK / 自托管 / 数据可导出 / 无行为追踪）
7. **最终 CTA** — 奶油底居中 64px 大标题（黄色句号）+ 副文 + 三按钮
8. **Footer（深色）** — Logo + 标语、三列链接、底栏版权 / 法条 / 社交图标（GitHub、X、邮件）

## 3. 产品操作页（3 屏，1440×900）

三屏共用同一套 App 外壳：浏览器栏（三点 + 地址 pill）+ 232px 侧边栏（Logo / MENU 导航 / 本周进度部件 / 用户卡）+ 主区域。侧边栏通过整体复制保证跨屏一致，仅切换导航激活态。

### 屏幕一 · 今日面板
- 页头：标题 + 日期周次 + 搜索 / 通知 / 头像操作组
- **新目标输入卡**：mono 眉题 + 大输入框（占位示例「三个月内通过日语 N3 考试」）+ 墨色「开始规划」按钮 + 3 个示例 chips
- **统计卡行**：进行中 3 / 今日待完成 5 / 连续学习 12 天 / 本周完成率 86%（第四张用黄色强调卡）
- **底部双列**：左「今日子任务」4 行（复选框三态：已完成深底白勾 / 进行中空框 / 待开始，含时间与 Bloom 元信息）；右深色「AI 修订建议」卡（2 条建议 + 应用/稍后 + 算法脚注）

### 屏幕二 · 任务详情
- 返回行 + 任务标题组 + 「AI 重新规划」描边药丸 / 「标记完成」墨色药丸
- 总体进度卡：标签 + 黄色进度条（62%）+ 百分比 + 子任务计数
- **甘特图卡**：图例（已完成/进行中/计划中）+ 7 日表头（周日高亮黄）+ 三条任务条（灰=已完成 L1-L4、黄=进行中 L5-L7、描边=计划 L8）
- **子任务清单卡**：4 行，状态图标三态 + 日期
- **子任务详情面板**（右 380px）：状态徽章、标题、2×2 元信息、任务描述、2 条学习资源（含来源与可信度标注）、3 条行动项、底部「完成此项 / 稍后」
- 悬浮 AI pill：「AI 正在核查排期 · 阶段 3/4」（与 Landing Hero  pill 同语言）

### 屏幕三 · AI 规划弹层
- 屏幕一底稿 + 45% 墨色遮罩 + 居中 720×640 白弹层（radius 20，大投影）
- 页头：台阶标识 +「AI 规划流水线」+ 关闭按钮
- **四阶段流水线**：意图解析 ✓ → 资源检索 ✓ → **计划生成 3（黄圈激活）** → 核查修订 4（描边待办），步骤间细连接线
- **当前阶段卡**：阶段标题 + 62% + 黄色进度条 + 描述 + 三项统计（6 子任务 / 8 资源 / 校验 6/8）
- **计划预览**：4 行子任务（序号章 + 标题 + 时长 + Bloom 层级）
- 底栏：取消提示 + 「取消」描边药丸 /「应用计划」墨色药丸

## 4. 设计决策说明

1. **为什么三级台阶做标识**：产品名「拾级」的直接视觉转译，递级结构同时暗示「排期递进」，顶点黄与全站唯一点缀色规则一致——标识即色彩系统的缩影。
2. **为什么黄色只做点缀**：奶油底上近黑文字已提供全部信息层级；黄色只出现在句号、顶点、进行中、强调统计卡与深底眉题五处，保证「稀有=重要」。
3. **为什么 App 界面用浅奶油而非纯白**：与 Landing 同底色延续品牌；白卡浮于奶油底上即形成层次，无需重投影。
4. **为什么深色卡给 AI 建议**：AI 是产品的「第二主角」，用 Landing 隐私带同款深色带让 AI 模块在界面里被一眼识别，黄色眉题保持暗底可读性。
5. **为什么弹层用遮罩 + 阶段流水线**：AI 规划是等待感最强的环节，四阶段（含勾选态）让用户随时知道「到哪了、还要多久」，预览列表则在等待中提前建立预期。
6. **跨屏一致性手法**：侧边栏整体复制而非重绘，导航激活态只改填充与字重；按钮、卡片、眉题全部复用同一组令牌。

## 5. 质量审查记录（5 维自评 + 修复清单）

评分（1–5）：哲学 5 · 层次 5 · 执行 4.5 · 特异性 5 · 克制 5

**已修复问题：**
- 核心能力网格 wrap 布局只排 2 列、右侧留白 584px → 重构为显式 2 行 × 3 列，卡片均分铺满
- Footer 链接列只占左半 → 改两端分布，三列均衡展开
- AI 建议正文单行溢出卡片 → 限宽 300 自动换行
- 弹层内容超出 580 框高、底栏被裁剪 → 弹层加高至 640 并重新居中
- 统计卡固定高度 127 有裁切风险 → 改自适应内容高度
- 侧边栏中段 558px 空洞 → 增加「本周进度」部件（进度条 + 学习时长）
- 版权文本 `©` 符号触发字形警告 → 改为 Copyright 文字
- Hero 左列右侧留白、导航两侧空隙：属有意的版式呼吸，保留

**残留说明：** 侧边栏弹性间隔（用户卡沉底）为有意设计；Landing 全页较长（约 4700px），浏览时按章节色带推进。
